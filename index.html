A few projects

Wireless Visual Command System for Deaf Curlers

A wireless system built on ESP32 and ESP-NOW that gives deaf curling athletes real-time visual game commands through a handheld transmitter and a wearable receiver.

ESP32COnshape
Watch demo ▸

Built to help deaf athletes receive real-time curling commands without relying on sound. The system uses ESP32 boards communicating over the ESP-NOW protocol, with C firmware driving a multiplexed reversing-radar-style display that shows distinct visual instructions like "Curl" or "Line".

The hardware is packaged into two 3D-printed enclosures modeled in Onshape. The system consists of a handheld transmitter controller for the skip, and a wearable hat-mounted receiver for the sweeper.

Automotive Airbag Simulator

A real-time simulation of an automotive airbag deployment system built in C on an STM32F407, using FreeRTOS for preemptive task scheduling.

STM32FreeRTOSC

Simulates an automotive airbag system's real-time behavior on an STM32F407 board. Task scheduling and inter-process communication run under FreeRTOS, using hardware interrupts, binary semaphores, and shared memory to coordinate sensor reads and deployment logic under strict timing constraints.

Airbag deployment logic is tied to accurate GPIO signaling, with UART logging used throughout development to validate response timing against the sequence of simulated crash events.

Real-Time Gesture Recognition System

An int8-quantized neural network trained in Python and ported to C++ for real-time gesture inference on a Raspberry Pi Pico with no host computer required.

TensorFlow Lite MicroPythonC++
Watch demo ▸

A gesture recognition pipeline trained end-to-end in Python, then quantized to int8 and deployed for standalone real-time inference on a Raspberry Pi Pico. Feature extraction (mean, standard deviation, min, and max per sensor axis), along with the quantization logic, was ported from Python to C++ to run natively on-device.

The final firmware includes a custom I2C sensor driver, a windowing buffer, and an inference loop written in C++.
